User Guide

About

The TDW Cuts Automation Tool generates 8 standardized analysis cuts from your roster data for think-cell charting. It automatically extracts L1 (Thinker/Doer/Watcher) and L2 classifications from your data.

The 8 Cuts
  1. Demographic 1 Summary — Count by first selected demographic
  2. Demographic 2 Summary — Count by second selected demographic
  3. Demographic 3 Summary — Count by third selected demographic
  4. L1 Split — Thinker/Doer/Watcher totals
  5. L2 vs L1 — Cross-tabulation of L2 categories by L1
  6. L1 vs Demo 1 — Cross-tabulation of L1 by first demographic
  7. L1 vs Demo 2 — Cross-tabulation of L1 by second demographic
  8. L1 vs Demo 3 — Cross-tabulation of L1 by third demographic
Input Requirements
  • Excel file (.xlsx or .xls)
  • One row per employee
  • L2 Classification column with format: L1 | L2 (e.g., "Doers | Dev/ Eng")
  • At least 3 demographic columns for analysis
Anomaly Handling

The tool will flag rows with:

  • Missing L1/L2 classification
  • Invalid format (missing "|" separator)
  • Unrecognized L1 category

Flagged rows are auto-categorized as "Unknown | Unknown". You can override these during review.

Output Formatting
  • All cuts on single sheet with clean block layout
  • Category names in grey italic (Cuts 1-3)
  • Descending sort order (blanks at end)
  • No merged cells (think-cell compatible)
